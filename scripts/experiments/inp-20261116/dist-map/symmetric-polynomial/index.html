対称多項式環

𝑋 =(𝑥1,…,𝑥𝑁) のなす整数係数多項式であって、𝑁 次対称群の元による変数の置換の元で不変なもののなす環（対称多項式環）Λ𝑁 ⊂𝐙[𝑋] を導入する。この環を生成する多項式の集まりとして以下のような形のものが知られている。

  • 冪和対称多項式 : 𝑝𝑛 =∑𝑁𝑖=1𝑥𝑛𝑖
    • 冪和対称多項式は有理数係数において対称多項式環を（代数的に）生成する: Λ𝑁 ⊗𝐐 =𝐐[𝑝1,𝑝2,…].
  • 基本対称多項式 : 𝑒𝑟 =∑1≤𝑖1<⋯<𝑖𝑟≤𝑁𝑥𝑖1⋯𝑥𝑖𝑟
    • 整数係数において対称多項式環を代数的に生成する
    • 𝑒0 =1, 𝑒1 =𝑝1, 𝑒𝑁 =det⁡𝑋
    • 𝑒𝑟<0 =𝑒𝑟>𝑁 =0
  • 完全対称多項式 : ℎ𝑟 =∑1≤𝑖1≤⋯≤𝑖𝑟≤𝑁𝑥𝑖1⋯𝑥𝑖𝑟
    • 整数係数において対称多項式環を代数的に生成する
    • ℎ0 =1, ℎ1 =𝑝1
    • ℎ𝑟<0 =0

Schur多項式

以下のようにしてSchur多項式を定める: 𝑠𝜆(𝑋):=𝑠𝜆(𝑥1,…,𝑥𝑁)=det1≤𝑖,𝑗≤𝑁⁡(𝑥𝜆𝑗+𝑁−𝑗𝑖)det1≤𝑖,𝑗≤𝑁⁡(𝑥𝑁−𝑗𝑖).ただし 𝜆 =(𝜆1,…,𝜆𝑁) は分割で、非増加非負整数列で表される: 𝜆1 ≥𝜆2 ≥⋯ ≥𝜆𝑁 ≥0. 長さが 𝑁 未満の分割についても、ゼロ埋めによって長さ 𝑁 の分割と見なして同様に定義される。長さが 𝑁 より大きい分割については 0 と定義される。分母は（符号を除いて）Vandermonde行列式であり、差積として表される: Δ(𝑋):=∏1≤𝑖<𝑗≤𝑁(𝑥𝑗−𝑥𝑖)=det1≤𝑖,𝑗≤𝑁⁡(𝑥𝑗−1𝑖).Schur多項式は対称多項式環の 𝐙-加群としての基底をなす。

母函数による関係式

基本対合

定義

基本対合 𝜔 は環 Λ𝑁 の代数としての自己準同型 𝜔(𝑒𝑘)=ℎ𝑘として定義される。関係式 ∑𝑛𝑖=0( −1)𝑖𝑒𝑖ℎ𝑛−𝑖 =0 から 𝜔(ℎ𝑘) =𝑒𝑘 も成り立ち（というのは、帰納的に 𝜔(ℎ𝑛)=𝑛∑𝑖=1(−1)𝑖+1𝜔(𝑒𝑖)𝜔(ℎ𝑛−𝑖)=𝑛−1∑𝑗=0(−1)𝑛−𝑗+1ℎ𝑛−𝑗𝑒𝑗(𝑗=𝑛−𝑖)=𝑒𝑛となることから分かる）、𝜔2 =id が保証される。つまり 𝜔 は代数としての自己同型である。

冪和対称多項式への作用

基本対合は冪和対称多項式に対して 𝜔(𝑝𝑘)=(−1)𝑘−1𝑝𝑘のように作用する。このことは以下のようにして分かる。完全対称多項式の母函数の対数を取ると log⁡𝐻(𝑡)=−∑𝑖log⁡(1−𝑥𝑖𝑡)=∑𝑖∞∑𝑘=1(𝑥𝑖𝑡)𝑘𝑘=∞∑𝑘=1𝑝𝑘𝑘𝑡𝑘となり、また基本対称多項式の母函数の対数を取ると log⁡𝐸(𝑡)=∑𝑖log⁡(1+𝑥𝑖𝑡)=∑𝑖∞∑𝑘=1(−1)𝑘−1(𝑥𝑖𝑡)𝑘𝑘=∞∑𝑘=1(−1)𝑘−1𝑝𝑘𝑘𝑡𝑘となる。ところで 𝜔(𝐸(𝑡)) =𝐻(𝑡) から 𝜔(log⁡𝐸(𝑡)) =log⁡𝐻(𝑡) が成り立つため、冪和対称多項式に対する作用が分かる。

Schur多項式への作用

基本対合はSchur多項式に対して 𝜔(𝑠𝜆)=𝑠𝜆Tのように作用する。このことは以下のようにして分かる。まずそもそもSchur多項式は、分割 𝜆 =(𝜆1,…,𝜆𝑛) に対してJacobi-Trudi公式により 𝑠𝜆=det1≤𝑖,𝑗≤𝑛⁡(ℎ𝜆𝑖−𝑖+𝑗)と表される。ここへ基本対合が作用すると 𝜔(𝑠𝜆)=det1≤𝑖,𝑗≤𝑛⁡(𝜔(ℎ𝜆𝑖−𝑖+𝑗))=det1≤𝑖,𝑗≤𝑛⁡(𝑒𝜆𝑖−𝑖+𝑗)となる。上式の右辺は双対Jacobi-Trudi公式 𝑠𝜇=det1≤𝑖,𝑗≤𝜇1⁡(𝑒𝜇T𝑖−𝑖+𝑗)において 𝜇 =𝜆T とおいたものであり、こうしてSchur多項式への基本対合の作用が分かる。

双対Newton恒等式

𝑋 =(𝑥1,…,𝑥𝑁),𝑌 =(𝑦1,…,𝑦𝑀) について 𝑁∏𝑖=1𝑀∏𝑗=1(1−𝑥𝑖𝑦𝑗)−1=∑𝜆𝑠𝜆(𝑋)𝑠𝜆(𝑌)が成り立つ。このことは以下のようにして分かる。まず一般性を失わずに（ゼロ埋めによって）𝑁 =𝑀 として正方行列の公式を使えるようにする。左辺に関連するCauchy行列式は差積 Δ を用いて det1≤𝑖,𝑗≤𝑁⁡(11−𝑥𝑖𝑦𝑗)=∏𝑖<𝑗(𝑥𝑗−𝑥𝑖)(𝑦𝑗−𝑦𝑖)∏𝑖,𝑗(1−𝑥𝑖𝑦𝑗)=Δ(𝑋)Δ(𝑌)∏𝑖,𝑗(1−𝑥𝑖𝑦𝑗)となることが、𝑥𝑖𝑦𝑗 =1 は極を与えること、𝑥𝑖 =𝑥𝑗 は零点を与えること、および次数、係数の比較から分かる。一方でこのCauchy行列の各成分を 11−𝑥𝑖𝑦𝑗=∞∑𝑘=0𝑥𝑘𝑖𝑦𝑘𝑗のように級数展開する。たとえば上式は 𝐴 =(𝑥𝑘𝑖) と 𝐵 =(𝑦𝑘𝑗) の積 𝐴𝐵T の (𝑖,𝑗) 成分とみなせる。ここでCauchy-Binetの公式を使って det⁡𝐴𝐵T を 𝑁 次小行列の行列式の積の和に展開すると det1≤𝑖,𝑗≤𝑁⁡(11−𝑥𝑖𝑦𝑗)=∑𝑘1>⋯>𝑘𝑁≥0det⁡(𝑥𝑘𝑗𝑖)det⁡(𝑦𝑘𝑗𝑖)となる。ここで 𝜆𝑗 =𝑘𝑗 −𝑁 +𝑗 によって分割 𝜆 =(𝜆1,…,𝜆𝑁) を定めると、この小行列式はSchur多項式に他ならないことが分かる: det𝑖,𝑗⁡(𝑥𝑘𝑗𝑖)=det⁡(𝑥𝜆𝑗+𝑁−𝑗𝑖)=(−1)𝑁(𝑁−1)2𝑠𝜆(𝑋)Δ(𝑋).従って Δ(𝑋)Δ(𝑌)∏𝑖,𝑗(1−𝑥𝑖𝑦𝑗)=∑𝜆(𝑠𝜆(𝑋)Δ(𝑋))(𝑠𝜆(𝑌)Δ(𝑌))となり、両辺を Δ(𝑋)Δ(𝑌) で割ればCauchy和公式が得られる。

双対Cauchy和公式

𝑋 =(𝑥1,…,𝑥𝑁),𝑌 =(𝑦1,…,𝑦𝑀) について 𝑁∏𝑖=1𝑀∏𝑗=1(1+𝑥𝑖𝑦𝑗)=∑𝜆𝑠𝜆(𝑋)𝑠𝜆T(𝑌)が成り立つ。このことは以下のようにして分かる。ここでも一般性を失わずに（ゼロ埋めによって）𝑁 =𝑀 とできるのでしておく。まずCauchy和公式の左辺の対数を取って展開すると冪和対称多項式が登場する: log⁡∏𝑖,𝑗(1−𝑥𝑖𝑦𝑗)−1=∑𝑖,𝑗∞∑𝑘=1(𝑥𝑖𝑦𝑗)𝑘𝑘=∞∑𝑘=1𝑝𝑘(𝑋)𝑝𝑘(𝑌)𝑘.つまりCauchy和公式は exp⁡(∞∑𝑘=1𝑝𝑘(𝑋)𝑝𝑘(𝑌)𝑘)=∑𝜆𝑠𝜆(𝑋)𝑠𝜆(𝑌)が成り立つと言っている。ここで 𝑌 のなす対称多項式環に関する基本対合 𝜔 を両辺に作用させると exp⁡(∞∑𝑘=1(−1)𝑘−1𝑝𝑘(𝑋)𝑝𝑘(𝑌)𝑘)=∑𝜆𝑠𝜆(𝑋)𝑠𝜆T(𝑌)となる。この左辺の指数関数の中身は ∑𝑖,𝑗∞∑𝑘=1(−1)𝑘−1(𝑥𝑖𝑦𝑗)𝑘𝑘=−log⁡∏𝑖,𝑗(1+𝑥𝑖𝑦𝑗)−1=log⁡∏𝑖,𝑗(1+𝑥𝑖𝑦𝑗)であるから、双対Cauchy和公式が示された。
