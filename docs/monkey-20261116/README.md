# モンキーテスト（2026-11-16）

記事の閲覧で、操作の組み合わせから起きる不具合を探した1回限りの調査の記録です。CIでは実行しません。スクリプトは `scripts/experiments/monkey/` にあります。対象は `60ea23c` のコードの本番ビルドを `astro preview` で配信したものです。

## 方法

`monkey.mjs run <engine> <article> <mode> <seed> <bursts> <outDir>` は、シードから操作の列を作って実行します。1回の実行は67の塊で、1つの塊は1〜5個の操作です。塊の中では0〜300msの間隔で操作を続け、描画が落ち着くのを待たないので、後半の本文の表示中、左右キーのアニメーション中、ページ遷移中にも次の操作が入ります。塊が終わると、状態が300ms変わらなくなるまで待ってから、不変条件を確かめます。

- 操作: ホイール（縦・横・斜め、1回と連続）、キー（PageUp／PageDown、Space、Shift+Space、左右上下、Home／End、Tab、Shift+Tab）、画面上の任意の点のクリック、標準スクロールバーのドラッグ、目次、式番号への参照、折りたたみ、コードのコピー、段組みの切り替え、画面サイズの変更、拡大、再読み込み、戻る・進む、閉じる・一覧から開く、URLでの直接表示（`?columns=` とハッシュ）、印刷表示、タッチのスクロール（Chromiumだけ）、待機。
- 拡大はCDPの `Emulation.setDeviceMetricsOverride` で、CSSの画面幅と `devicePixelRatio` を変えます（Firefoxは画面幅だけ）。`html { zoom }` は使いません。Astroのページ遷移で `<head>` から消え、遷移の途中で倍率が変わってview transitionが中止されるためです。
- `batch.mjs <engines> <seeds> <bursts> <outDir> <並列数>` は、記事4本（`symmetric-polynomial`、`nextjs-mdx`、`how-to-write`、`tips-haskell`）と1段・n段の組み合わせを実行します。
- `monkey.mjs replay <record.json>` は記録した操作の列を再生します。`minimize.mjs` は、同じ不変条件が失敗する範囲で塊を減らします。
- `monkey.mjs selftest` は、複製の段のブロックを消す・ずらす、論理座標を書き換えるという故障を入れ、不変条件が失敗することを確かめます。

## 不変条件

1. `pageerror` と `console.error` が出ない。遷移中に画面サイズが変わったり文書が隠れたりして、ブラウザーがview transitionを中止したエラーは除く。
2. 画面幅が320px以上のとき、ページ全体が横にはみ出さない。
3. n段で、見えている各段に、その段の論理位置にある元本文のブロックが、同じテキスト・縦位置・高さで表示されている。
4. n段で、論理座標とネイティブのスクロール位置が1/1024 px以内で一致する。2段以上が入る画面で全段が空白にならず、外側の空白の段が1段以下である。
5. 落ち着いた後に、後で表示する本文（`data-cl-defer`）が残っていない。表示中にキーかポインターで操作した直後には、残りがすべて表示されている。
6. フォーカスが、複製の段・`aria-hidden`・`inert` の中にない。
7. 再読み込みと、戻る・進むだけの塊の後に、離れたときの読書位置へ戻る（同じ段組み・画面サイズ・倍率・折りたたみのときだけ比べる）。
8. 記事を開いている間は背景の一覧が `inert` と `aria-hidden` で、一覧ではどちらもない。閉じた後のフォーカスが元の記事のカードにある。

## 結果

シード1〜10 × 記事4本 × 1段・n段 × Chromium・Firefoxの160回、各エンジン約1万6千操作です。`run2-summary.jsonl` が実行ごとの失敗の数、`run2-records.tgz` が全実行の操作の列・結果・検査の回数です。`run1-summary.jsonl` は誤検知を直す前の1回目の結果です。

- 不変条件6がChromiumで4回失敗した。2回は、横にはみ出したディスプレイ数式の複製にTabで止まる不具合で、PR #53で直した。修正後のビルドでは、この2回の操作の列を再生しても失敗しない。残りの2回は、複製の段のリンクをクリックしたときにフォーカスが複製に残る動作で、`docs/column-layout.md` の「制約」に書いた（`8c20076`）。
- ほかの不変条件は失敗しなかった。Firefoxの失敗はなかった。

1回目の実行で出た次の失敗は、テスト側の誤りだったので直した。

- 一覧ページで再読み込みしたときにも読書位置を比べていた。
- 読み込み中やスクロール中に、戻る・進むの比較の基準になる位置を記録していた。基準は、落ち着いた直後に記録した位置だけにした。
- 一覧から記事へ移る途中に、落ち着いたと判定していた。
- 拡大後の幅が320px未満のときの横のはみ出しは、ページの最小幅が320pxなので除いた。
- 1段しか入らない画面で、縦の操作によりその段が空白になるのは、`docs/column-layout.md` の「座標と移動範囲」に書いてある動作なので除いた。
